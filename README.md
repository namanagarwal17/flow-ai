# 🚀 Flow AI

Flow AI is a modern no-code workflow automation platform that allows users to visually design, execute, and monitor automation workflows using a drag-and-drop interface.

---

## 🧠 Features

* 🎯 Drag-and-drop workflow builder (React Flow)
* ⚡ Real-time workflow execution engine
* 📜 Terminal-style live logs (animated)
* 🔄 Trigger → Action → Condition flow support
* ⏱ Execution time tracking
* 🧠 AI step simulation
* 📧 Email step simulation
* 🌙 Dark mode console UI

---

## 🏗️ Tech Stack

**Frontend**

* React
* React Flow
* Tailwind CSS

**Backend**

* Node.js
* Express.js

---

## ⚙️ How It Works

1. User creates workflow using nodes
2. Clicks "Run Workflow"
3. Backend processes steps sequentially
4. Logs stream in real-time to UI
5. Execution completes with status + time

---

## ⚡ Execution Console

* Live streaming logs
* Color-coded steps:

  * [TRIGGER]
  * [AI]
  * [EMAIL]
  * [ERROR]
* Terminal-style UI with animation

---

## 🧪 Demo Mode
